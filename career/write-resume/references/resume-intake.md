# 简历信息采集指引

## 使用方式

这份指引用于生成完整简历、大范围重写，或用户不知道应提供哪些材料的场景。先阅读用户已经提供的简历、JD、作品集、个人主页、经历笔记或其他附件，从中提取可用信息；只向用户索取尚未掌握且会影响成稿的信息。

不要要求用户把事实预先写成简历语言。鼓励用户提供原始、零散、未经润色的信息，后续由 Agent 负责归纳、排序和表达。用户可以把未知、不适用或不愿披露的字段标记为“待补充”“不适用”或“不披露”。

涉及姓名、电话、邮箱、详细地址等个人信息时，说明这些内容只有在用户希望写入正式简历时才需要提供。不要索取身份证件、账号密码或与简历无关的敏感信息；允许先使用占位符或匿名信息完成草稿。

## 采集策略

1. 先用简短清单告诉用户已经掌握了什么，再列出关键缺口。
2. 如果缺失信息较多，提供下方可复制模板，让用户一次性填写；如果只是修改一段经历，只选择相关字段追问。
3. 优先补齐会影响岗位定位、内容取舍和可信度的信息：目标 JD、候选人个人职责、行动与决策、结果指标、时间范围和可自证边界。
4. 用户暂时无法补齐时，继续生成带明确占位符的草稿，并把待确认项集中列出。不得自行补造数字、职级、公司信息、技术细节或 ownership。
5. 信息收齐后，用一句话复述目标岗位和候选人的核心卖点，请用户纠正事实性误解；不需要让用户逐句批准 Agent 的正常写作与排版工作。

## 信息回收后的检查

开始正式写作前确认：

- 目标岗位和主要读者明确，或已说明采用的合理假设；
- 每段核心经历都能区分团队结果与候选人个人贡献；
- 最强主张至少有行动、范围、结果或可信证据支撑；
- 日期、职位、公司、教育和联系方式不存在明显冲突；
- 不确定信息已标记，没有被写成确定事实；
- 保密、匿名化、格式和语言要求已经记录。
