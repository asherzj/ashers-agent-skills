---
name: research
description: 对照高信任度的一手来源调查某个问题，并把发现以 Markdown 文件的形式记录到仓库中。当用户希望研究某个主题、收集文档或 API 事实，或将阅读跑腿工作交给后台代理时使用。
---

启动一个**后台代理**去做调查，这样它阅读时你可以继续干活。

它的任务：

1. 对照**一手来源**（官方文档、源代码、spec、第一方 API）调查问题，而不是它们的二手转述。把每条论断追溯到拥有它的来源。
2. 把发现写进单个 Markdown 文件，为每条论断引用其来源。
3. 保存到仓库已存放此类笔记的位置；遵循现有惯例；如果没有惯例，就放到一个合理的位置并说明放在了哪里。
