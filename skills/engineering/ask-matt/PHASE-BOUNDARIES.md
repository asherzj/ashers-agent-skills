# 阶段边界

**阶段（phase）**是会话内的一块工作：拷问（grilling）、实现、QA。这个定义故意保持模糊：当你觉得*"好，这部分搞定了"*时，一个阶段就结束了。

**阶段边界**是两个阶段之间的空隙，也是这个决定唯一该做的地方。阶段中途没有要做的决定：要么继续，要么把剩下的工作拆给子代理。在阶段中途压缩会让代理丢掉主线。

## 五个选项

| 选项            | 作用                                                                |
| ------------ | --------------------------------------------------------------- |
| **继续**       | 留在本会话中。完全没有上下文切换。                                        |
| **`/clear`**  | 清空上下文窗口，从零开始。                                                |
| **`/handoff`** | 写出一个可携带的 markdown 文件，并用它随处播种一个会话。                     |
| **子代理**     | 把任务送到它自己的上下文窗口，换回一份报告。                                 |
| **`/compact`** | 压缩当前上下文，并用摘要播种一个新会话。                                     |

## 决策树

在边界处自上而下地走。第一个**"是"**胜出。

**1. 还能在这个会话里继续吗？** 两件事会让答案为"是"：下一个阶段需要把本阶段当作**一手来源**，或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 15 万 token）还装得下下一个阶段。拷问 → 实现是标准的"是"：实现要的是逐字保留的推理，而不是它的摘要。继续零成本、零损失，所以应最先尝试排除它，再谈其他选项。

**2. 上下文与接下来的工作无关吗？** 本会话里的所有东西（探索、决策、死胡同）都是可丢弃的吗？如果是，**`/clear`**。这是棋盘上最便宜的一步：不花时间，还回整个窗口。`/clear` 也不是终点：旧会话仍然可以恢复。

把这一步走错的代价是单向的。清掉一个_相关_的上下文，你就失去了所构建之物背后的**为什么**，把 diff 重读多少遍也换不回来。

**3. 需要移交吗？** `/handoff` 适用面很窄。只有当你处于以下情形时才需要它：

- 换到**新的 harness**（Claude → Codex），
- 挪到**新目录**或另一个仓库，
- 把工作交给**同事**，
- 或在**阶段中途**分出一个支线任务，而不打乱手头的工作。

这份清单就是全部条件。`/handoff` 买到的是**可携带性**：一个能随身带走的文件。如果没有东西需要带走，就不需要它。

**4. 这个任务能离手完成吗？** 它的范围是否收得足够紧，能在你离开键盘、无需掌舵的情况下运行？那就把它交给**子代理**，本会话原封不动。自动化评审是标准场景：代理读 diff 并汇报，其间不需要你。

**5. 否则，`/compact`。** 上下文仍然相关、harness 不变、目录不变，而你又需要留在环里：树会落在这里，而且常常落在这里。给它带上一条指令（`/compact we're going to QA this area`），好让摘要保留下一个阶段需要的东西。

`/compact` 是**默认项，而不是第一选择**。它位于最底部，因为在它之上的四个问题都更便宜或更精确。人们从它开始时的失败模式是：新会话对某个被摘要压平的决策自信满满地搞错。

## 一手来源与二手来源

除**继续**之外的每一步棋都会把**一手来源**变成**二手来源**：实际发生过的会话，被它的摘要所取代。这笔交易的形状永远一样：

| 来源                              | 信息量 | 噪声 | 回旋余地 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（继续）                      | 完整        | 多    | 小           |
| 二手（`/compact`、`/handoff`）    | 有损        | 少    | 大           |

这就是问题 1 排在最前面的原因。只有当留下来的代价高于它省下的，你才去支付这份有损。

## 这些是主观判断

这些问题并不客观：每一个里面都有品味的成分，同一个边界在不同的两天里可能走向两条路。价值在于**按顺序**提问，并且在边界处问，而不是在工作的中途问。
